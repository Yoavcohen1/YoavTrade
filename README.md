# YoavTrade

**Android Virtual Stock Trading Platform**

YoavTrade is an Android application developed using Java, Firebase, external APIs, and Google Gemini AI.

The application provides a virtual stock trading environment, allowing users to explore financial markets, manage virtual investment portfolios, track stocks, and interact with AI-powered features.
